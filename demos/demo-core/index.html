Forced light / dark modes

Any element can pin its subtree to a specific mode using themeMode="light", themeMode="dark", or themeMode="invert" — regardless of the global toggle above.

themeMode="light"

Always light, even when the page is in dark mode.

Density

Use [themeDensity="-2"] on any ancestor to shift --density-scale in that subtree. Container padding uses --space--lg by default, which is density-reactive. Supports -5 (most compact) to 5 (most spacious).
